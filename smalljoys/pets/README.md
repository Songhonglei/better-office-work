## 怎么使用

### 先下载

点击对应的 ZIP，进入文件页后选择 **Download raw file** 下载，解压后得到一个宠物文件夹。每包包含 `pet.json`、`spritesheet.png`、独立说明和许可证。

### Codex 本地宠物

素材包沿用本机现有的 `pet.json` 格式：

1. 将解压出的宠物文件夹放入 Codex 的 `pets` 目录，默认是 `~/.codex/pets/`；使用自定义 `CODEX_HOME` 时，放到该目录下的 `pets/`。
2. 若已有同名目录，先备份。重启客户端，再从宠物列表选择。
3. 移除时先切换到其他宠物，再删除对应的本地文件夹。

仓库中的配置与本机格式一致；不同客户端版本是否支持本地宠物，以实际客户端为准。

### ChatGPT Work 宠物

将 `spritesheet.png` 交给支持自定义宠物的 Agent，要求「使用此精灵图创建宠物」。是否可导入及需要的校验，以当前客户端和工具结果为准。ZIP 是素材包，下载不会自动创建云端宠物，也不会改变当前使用的宠物。

### 其他客户端

可使用完整精灵图适配；`pet.json` 不是通用插件标准，其他客户端通常需要自行配置动作。

## 素材格式

- PNG / RGBA，1536 × 2288，8 列 × 11 行，单帧 192 × 208。
- v2 精灵图，透明背景；未修改原始宠物图像。
- `preview.gif` 从原图裁帧生成，浅色底仅用于预览。
- [SHA256SUMS](./SHA256SUMS) 提供配置、图片、预览和 ZIP 的 SHA-256，可在本目录运行 `shasum -a 256 -c SHA256SUMS` 核对。
