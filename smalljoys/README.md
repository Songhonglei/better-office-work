# Small Joys · 工作小乐趣

忙里偷个闲，给工作添点小乐趣。

这里收集自制或可分享的小玩意：皮肤、虚拟宠物、放松小游戏、趣味插件。轻巧、好用，打开就能知道怎么玩。

## 收录约定

- 每个作品单独放一个文件夹，写清用途、用法和适用环境。
- 图片或动画尽量提供预览，需要安装的作品说明安装和移除方法。
- 仅提交可公开分享的素材，不带账号信息、凭据、临时下载链接或个人运行配置。
- 自制内容沿用仓库的 [MIT License](../LICENSE)；后续引入外部素材时，单独注明来源与许可。
