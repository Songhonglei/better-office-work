# 修辞与抒情参考 · R-CN1–R-CN6

适用于需要修辞分析的散文、诗歌、小说、文案或抒情段落。短句也可分析；不能仅凭词语和句式判断作者来源。意象密度、重复和省略可以是作者有意的选择。

参见 [中文风格参考](style-patterns-cn.md) 与 [同位语例句](lyrical-appositive.md)。

## 抒情同位语

示意结构：`本体 + 逗号 + 修饰语 + 的 + 喻体`。例如虚构练习句「黄昏，大地温柔的信使」。也可用破折号、内嵌或独立成句形式。任何变体都不证明或排除某种作者来源。

## 六个阅读问题

| 代码 | 观察 | 可选编辑 |
|---|---|---|
| R-CN1 | 多个同位语是否让叙事停滞 | 留下有效意象，删重复信息；不设全篇数量上限 |
| R-CN2 | 重复句式是否有节奏或强调作用 | 保留有作用的重复；确有单调问题时按含义调整，不为变体而变体 |
| R-CN3 | 熟悉的喻体是否准确服务本篇 | 常见意象也能有效；若空泛，可还原原文已有动作，不编私人细节 |
| R-CN4 | 形容词是否增加具体信息 | 试读删除后的句子，保留有效修饰，不能一律删词 |
| R-CN5 | 意象之间是否有可理解的联系 | 澄清转换、选择主线或减少冲突；并置也可能是有意设计 |
| R-CN6 | 情绪是否有足够的文本支撑 | 指出缺少的材料；有真实材料才补入，无材料时可删减，不捏造经历 |

抽象诗歌不必有个人记忆，非虚构叙事也不必改成第一人称。编辑应说明阅读效果，不把自己的审美当硬规则。

## 机械读数的限制

脚本在 `--lyrical` 或 `--tier literary` 下提供：

- `X，Y的Z` 形态的句数、最长连续句数、单段峰值及句数占比。
- 词库「信使、信笺、叹息、诗篇、守望者、耳语、序章、独白、回响」和「温柔、沉默、浪漫、治愈、漫长、细碎」的出现数与明细。

全部为 INFO，无质量阈值，不影响严格模式退出码。正则无法识别名词性、谓语或隐喻关系：「我站在窗前，想起那些远去的日子」也可能被粗计入。回原文人工复核，不把粗计当语法识别，不以词频判定抄袭、作者来源或审核结果。旧版「满足若干条即高度疑似」结论废弃。

## 改写边界

优先用原文已有的场景、动作和事实改善表达。若作者希望创作新场景，确认其虚构用途并标识；未提供的纸箱、凉水、旧物或童年不能直接写成亲历。准确保留日期、数量、引语、链接和必要披露；发现数字矛盾时在说明中请作者核实，不靠删整句藏起问题。
