# ImageGen 批量生图（防覆盖 + 避让水印 + 规范归档）

一次生成多张同风格图，最怕三件事：**文件互相覆盖、水印留在画面上、人物塌成同一张脸**。
本 skill 把这三件事的处理顺序和判断标准固定下来——先防覆盖，再避水印，最后才谈画面好不好看。

> 版本历史见 [CHANGELOG.md](./CHANGELOG.md)。

## 何时用
一次生成 2 张以上图片，尤其同风格系列图（公众号封面+配图、正文插图、卡片等）。

## 工具的三个已知坑（必须记住）
1. `output_dir` 参数可能被忽略 → 文件落到默认目录（如 `generated-images/`）。
2. 文件名 = 「截断的提示词前缀」+「秒级时间戳」。
   → 提示词开头相同时，并行生成落在同一秒 = 文件名完全相同 = **互相覆盖、静默丢图**。
3. `size` 非标准比例会被归一化到预设（实测请求 1536x654 会变成 1408x704=2:1）。
   → 要 2.35:1 微信头条封面等非标准比例：先生成接近比例（如 2:1 或 16:9），再用 sips/PIL 裁剪：
     ```bash
     sips -c 599 1408 in.png --out crop.png      # 从 2:1 中心裁成 2.35:1
     sips -z 383 900 crop.png --out cover.png     # 缩放到微信标准 900x383
     ```
   → 微信头条封面标准 900x383（2.35:1），次条 200x200（1:1）。

## 生成前：提示词规范（防覆盖 + 避让水印）

### ① 开头加唯一前缀（根治覆盖）
每张图的 prompt 第一个词用唯一标记，让文件名前缀不同：
- 推荐用场景词开头：如「市井八仙。」「天庭道观对比。」「凡人互助。」
- 或简单序号：「图01」「图02」…（模型通常忽略这些标签词，不会画进画面）
- 效果：即使并行 + 同一秒，文件名也不会撞。（**但 2026-10-06 起建议顺序发**——并行会撞 ECONNRESET，见 ④。前缀仍要加，是第二道保险。）

### ② 右下角留白（避让 AI 水印）
AI 水印固定在右下角，且用户会裁掉它。所以 prompt 里必须明确：
- **右下角留白**，不放任何重要元素（印章、主体、文字、关键细节）。
- 印章 / 朱砂红点缀统一放**左下角**或画面左侧，不要放右下角。
- 可在 prompt 追加一句：「右下角留白，不放置任何元素」。
- 效果：裁掉右下角水印时，不损失任何画面内容。

> ⚠️ **但模型经常不守这条（2026-09-26 实测）**：一批 4 张 1536x1024 的插图，prompt 里明确写了「右下角大面积留白」，结果 4 张的右下角**全都有内容**（墙面、地面、桌角、纯黑）。**不要假设留白指令生效**，必须走下面的「量水印 → 按量裁」流程，不要凭感觉裁。上面这条只能提高「裁掉不心疼」的概率，不是保证。

### ③ 提示词直接写中文，不要用 `\uXXXX` 转义拼

**2026-10-06 实测**：用 Unicode 转义拼中文 prompt，转义表极易写错，实际发出去的是**形近/同音错字**——
本次真实发生三处：`修葺`→`修荠`、`垛口`→`垆口`、`下颌`→`下顸`。模型靠上下文猜对了，画面没坏，
但**这是在赌**：错字恰好落在关键名词上（如"夯土"写成"芬土"、"垛口"写成别的）就会直接画错。

规则：prompt 一律直接写中文，不做转义拼接。若不得不用转义，**发出去前先把 prompt 原样打印出来核对一遍**。

### ④ 并行 3 张以上会撞 `ECONNRESET`

**2026-10-06 实测**：一次并行发 3–4 张，出现整批 `read ECONNRESET`（3 张全失败，无文件落盘）。
改成**一次一张顺序发**后 6 张全部一次成功。判断标准很简单：**失败时先 `ls` 目标目录**——
文件数没涨就是彻底没生成，直接重发即可，不必换提示词。
（见下方批量策略：现在**默认改成顺序发**，唯一前缀仍要加，它是防同秒覆盖的第二道保险。）

### ⑤ 想把某物画小 / 画远，要改「形状」，不要只给「数值」

**2026-10-06 实测（《长城》配图 `03-界桩迟到` 重出）**：题材要一根「水泥界桩」在远景里只当个小物件。
连试三版，写了「非常小」「只占画面极小的一块」「高度不到画面高度的十五分之一 / 二十分之一」，
模型每次都画成**又高又窄的竖长方形**——读起来是块「无字碑」，跟题材要的「工程标志桩」正好相反。
第四版改法（生效），三条一起上：

1. **改形状比例**：「矮胖的方块墩子，高度跟宽度差不多，上边略窄、底盘略宽，顶上是一道斜切面」
   ——把它从「石板」重新定义成「墩子」；
2. **给工程件特征**：「底部有一圈稍宽的水泥底座」——一眼能认出是标志桩而不是碑；
3. **写负面排除**：「绝不是竖长的长方形，也不是立起来的石板、不是石碑」。

规则：**尺度数值只在模型已经画对形状时才有效**。想把一个物件变小 / 变远，先去改它的**长宽比和部件**，
再用负面清单封死它最容易塌成的那个形状。同理，**材质也吃这一套**：只写「夯土筑的」它照画砖石砌缝，
要写「整道墙体是一体的夯土，从墙顶到墙根没有任何砖石码放的砌缝」才立得住（同轮实测）。

### ⑥ 古代场景的人物，必须逐件钉「头」和「衣」，只写朝代名无效

**2026-10-25《众口铄金》实测**：prompt 里写了「东汉汝南」「明崇祯三年北京西市」，人物出来是**民国**——
短发平头、立领长衫、西装领、纽扣。**白描线稿去掉色彩与纹样后，模型只剩一个默认朝代，而这个默认值是清末民初。**
**人物越多越错**（5 人以上必错，且常出现三四个时代混搭）。

三条一起上才压得住：**① 头发写束法**（「束发挽成髻，用发带或巾包住」+ 负面「不是短发、平头、寸头」）；
**② 衣写形制**（「交领右衽、宽袖、腰系带、下摆及踝」+ 负面逐个点名「立领／翻领／衬衫领／纽扣／对襟短褂（马褂）／中山装」）；
**③ 人群写统一**（「所有人一律同一朝代装束，没有一个人例外」）。
背影图尤其要管后脑——**短发是一个光圆弧，束发是一个髻**。

各朝代发式／冠巾／衣装的对照表，见 `references/style-library.md` 的 `baimiao-ink` →「古代场景的人物造型（朝代锚点）」。

## 生成后：立即改名归档

不依赖 output_dir，统一落默认目录后，用 mv 归位并改名：
```bash
mkdir -p output/<目标目录>
mv generated-images/<新生成文件> output/<目标目录>/NN-描述.png
```
命名规范：`NN-描述.png`（NN 两位序号，按文章/画面顺序，如 00-封面、01-众生相）。

## 交付前：数量核对 + 裁水印

### 数量核对（兜底）
```bash
ls output/<目标目录>/ | wc -l
```
确认文件数 = 预期数再交付。发现少了就是被覆盖，立刻补生成缺失的。

### 裁掉右下角水印

**先量，再裁——不要猜裁剪量。** 水印位置是固定的，量一次就能复用到同尺寸的所有图。

脚本只依赖 Pillow，先确认装好：
```bash
python3 -c "import PIL" 2>/dev/null || python3 -m pip install -q Pillow
```

**① 量水印上沿**：把右下角放大并画坐标刻度，直接读出「水印从第几行开始」：
```python
from PIL import Image, ImageDraw
im = Image.open(path).convert('RGB'); w, h = im.size
box = (w-300, h-180, w, h)                     # 右下角 300x180
c = im.crop(box).resize((600, 360), Image.LANCZOS)   # 放大 2x
dr = ImageDraw.Draw(c)
for y in range(0, 360, 20):                    # 每 20px 画一条刻度，标真实坐标
    real = h - 180 + y // 2
    dr.line([(0, y), (14, y)], fill=(255, 0, 0)); dr.text((16, y-5), str(real), fill=(255, 0, 0))
c.save('/tmp/wm_ruler.png')
```

**② 按量裁掉底部**（`sips -c` 是**居中**裁，做不到只裁底边，必须用 PIL）：
```python
CUT = 80                                        # 经验值：1536x1024 的图，水印上沿约 y=953 → 裁 80px 稳
im = Image.open(path)
im.save(raw_dir + f)                            # 原图先留档，别丢
w, h = im.size
im.crop((0, 0, w, h - CUT)).save(path)          # 覆盖为净版
```

**③ 验真**：看交付图右下角 80x260 区域，**不该再出现文字状笔画**（`max` 突变到 250+ 通常就是水印还在）。把几张图的右下角拼成一张对照图，一眼就能确认。

**经验值（1536x1024 输出，实测 2026-09-26）**
- 水印「AI生成 / WORKBUDDY」占 y≈953–1015、x≈1413–1521（宽约 110px，右边缘留 15px 余量）
- 裁 80px（→1536x944）可干净去除，4 张全部验真通过
- **封面类的横长图，纵向裁过就没有水印**：1408x704 的封面水印约在 y≈650–704。中心裁到 599 高、或只裁底部 68px（→1408x636）都能干净去掉。经验值：**保留下来的底边只要在 y<645 就安全**。
- 副作用可接受：裁掉的是一条底边，构图损失很小；若某张图底部恰好是重要内容，改用 PIL 补图（从水印上方同宽度区域垂直复制一条贴上去），但只在背景均匀时才用，否则会有拼接痕迹

**⚠️ 「暗像素剖面法」只在水印是深灰时有效（2026-10-17 实测）**：会话看不了图时，可用「右下角区域内逐行统计暗像素（灰度<110）」定位水印上沿。但《诺奖查证件》那批 6 张，右下角最小灰度只有 **122–175**、无成片深色笔画，剖面整段为 0 —— **这版水印极淡**，方法直接失效。→ **测不到 ≠ 没有水印**：一律按经验值裁（下节数值）＋裁后复测右下角，别因为"看起来干净"就不裁。

- 若模型会话看不了图、无法自查水印是否已去掉，交付时明确提示用户确认。

## 相框感（留白边框）—— 可选，默认不做

**默认不加框。**留白是审美偏好、不是通用需求：给每张图都套一圈白边等于替用户做了决定，还会改变成品尺寸
（1536x944 的插图被套成 1670x1078）。**只有用户明确说「要留白边 / 相框感 / 装裱感」时才加。**

prompt 里写「四周留出整圈空白」模型**基本不遵守**（2026-09-26 实测：写着「四周留整圈空白」，4 张全是满构图）。
所以一旦要加，**只能后期加**，别指望 prompt。

脚本：`scripts/add_frame.py`（已用《关口》母版做过像素级复现验证）。**这个脚本默认只做裁切**，
加框必须显式传 `--frame`。

**加框时的结构**：图像 → 白隙 gap → 〔细线框 line，可选〕 → 外侧白边 pad

| 参数 | 默认 | 说明 |
|---|---|---|
| `--frame` | 关 | **加框总开关。默认不加**，只有用户要求时才传 |
| `--pad` | 0.06 | 外侧白边，取**短边**的比例；5%~6% 观感最好，再宽显空 |
| `--gap` | 11 | 图像与线框之间的白隙（px）；`--line 0` 时它就是图像到外沿的留白 |
| `--line` | 3 | 线框粗细（px）；色用 `#1e1e1e`，纯黑太硬。**传 0 = 只留白边不画线** |

> **加框时用纯留白边，不要黑线（2026-09-26 用户拍板）**：带线版更像「版画装裱」，但线条画本身已有大量黑色轮廓，
> 再叠一道画框线显得生硬。**加框时一律 `--line 0`**，除非用户明确说要画框。
>
> **改边不必重出图**：带水印原图留了档，改白边宽度 / 去线 / 换比例只要重跑一次脚本（几秒），不要再去调生图。

```bash
S=scripts/add_frame.py

# 默认流程（不加框）——只裁水印
python3 "$S" in.png out.png --crop-bottom 80
# 封面：裁水印 + 裁到 2.35:1，再 sips -z 383 900 缩到微信标准尺寸
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35

# 仅当用户要求留白边时，才加 --frame
python3 "$S" in.png out.png --crop-bottom 80 --frame --line 0
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35 --frame --line 0          # 留白后恰为 2.35:1
python3 "$S" in.png out.png --crop-bottom 70 --frame --ratio 1 --pad 0.04 --line 0  # 方形次条封面
```

**⚠️ 加框会改变整体比例**，且 `pad = int(min(w,h) * ratio)` 依赖短边——短边又随裁切变化，**手算必然错**
（实测手算得 2.377，实际目标 2.35）。要精确到目标比例就用脚本里的二分 `fit_ratio()`，不要自己套公式。
不加框时 `--ratio` 直接就是图像本身的比例，没有这个问题。

**注意**：白边会把右下角水印推到视觉边缘，但**裁水印该做还得做**，不要用加框代替（何况现在默认不加框）。

## 批量策略

**默认顺序发（2026-10-06 修订）**：一次一张、等结果再下一张。原因是并行会撞 `ECONNRESET`——
本次 6 张的活，并行 4 张时挂 1 张、并行 3 张时 3 张全挂；改顺序后 6 张全过。慢一点，但不用返工。

- 每个 prompt 开头**仍要加唯一前缀**（防线①，防同秒覆盖）——顺序发时它是冗余保险，但成本为零。
- 数量多（6 张以上）：顺序发 + 发完立即 `mv` 归位改名，别攒到最后一起搬，避免和张三李四的文件混在一起。
- 大批量（10+ 张）：用 TaskCreate 建清单，逐张勾进度，避免"中间看着 OK 就停住"。
- 若确实要并行，**每批不超过 2 张**，且失败时先 `ls` 目标目录确认是否落盘，再决定重发哪张。

## 附：风格提示词模板

> **风格已命名，档案在 `references/style-library.md`**（名字 / 定位 / 招牌配方 / 可复用后缀 / 后期参数）。
> 以后调用直接说名字即可：**`白纸速写`（paper-sketch）**、**`水墨文艺风`（ink-wash）**、**`白描水墨`（baimiao-ink，人物白描＋环境水墨，三色，2026-10-17 首用 6/6 过）**。
> 用户说「**简笔水墨画**」→ 走 `baimiao-ink` 的**「线描主导」变体**（连环境也降为线描，只有一点极淡赭金；佛像类必守「只画侧脸轮廓、不做正面近景」，见同节，2026-10-17《佛像衣服》6/6 过）。
> 用户说「**简笔水墨 + 幽默／夸张／小冒犯的漫画**」→ 同风格的**「漫画夸张」变体**（2026-10-17《诺奖查证件》6/6 过）：线与笔不动，只换情绪词，并把夸张**只落在比例与姿态**（人极小/物极大、后仰、翘腿、长影子），面部照旧不刻五官；冲突靠**道具刻薄**而不是表情刻薄（空画框、被墨线划掉的书脊、往身后藏的空白牌子）。见同节。
> 本章保留速查配方；要新增风格，先在这里写配方，再往风格库补一份命名档案。

### 水墨文艺风 · `ink-wash`（历史 / 文化类公众号，2026-09-15 实测有效）

**统一风格后缀**（每张 prompt 末尾都粘这段）：
```
淡墨为主，古旧宣纸质感，文艺气质，留白多；画面不出现任何文字、题跋或印章字样；
左下角一枚极简朱砂印记；右下角留白，不放置任何元素。
```

**要点**
- **前缀用 4 字场景词**（如「葫芦小院」「墙里墙外」），既是防覆盖标记，也能让模型先抓住画面主题。
- 调色只允许三种：淡墨 + 极淡赭石/赭黄（暖）+ 一点极淡花青或藤黄（冷/光）。**朱砂只用在左下角那枚印上**。
- 留白要写进正文而不是只写"留白多"，例如「湖面以大片留白化作雾气」「地面留白成刺眼的白光」。
- 人物用"寥寥数笔勾勒""身形疏淡"，不要写面部细节——写意比工笔稳。
- **人物年代不写死就默认古装**。若要现代场景（如今日排队、当代街景），必须在 prompt 里点明"现代装束"，否则出来是水墨古装。
- 封面走**横向长卷**：`size` 传 `1408x704`（2:1），再 `sips -c 599 1408` + `-z 383 900` 得微信头条 900x383。
  内容插图统一 `1536x1024`（3:2），公众号正文宽度下观感舒服。
- 组图与文章走向对齐：**一张封面立主题，其余按小标题顺序各配一张**，不要六张同风格空镜。

**实测有效的一组分镜（拆墙 / 装墙主题）**
`北国拆墙`（长卷：北国城郭 ｜ 江南水乡，中间一道墙断开豁口）→ `葫芦小院` → `午门排队` → `西湖无墙` → `墙里墙外`（一道素白高墙横贯，墙外一人仰头看，墙内一人背墙坐）→ `霜降葫芦`。
其中「墙里墙外」这类**用构图直接对应论点**的图，比纯风景插图被引用率高得多。

### 白纸速写 · `paper-sketch`（小说 / 纪实 / 年代题材，2026-09-26 实测有效）

> 原名「简笔黑白 + 现实主义」，2026-09-26 命名。**白纸上一幅钢笔速写：白底黑线，几乎不上灰阶，四周一圈纯白当画框。**
> 完整档案（含四根支柱速记、命名备选）见 `references/style-library.md`。

**统一风格后缀**（每张 prompt 末尾都粘这段）：
```
纯粹黑白，只有黑、白和少量灰阶，不出现任何色彩；以简笔线条为主，笔触克制干净，
阴影用少量交叉排线表现；写实比例与真实年代细节，人物面部不做美化、不卡通化，
保留粗粝的生活质感；画面不出现任何文字、数字、书法、落款或印章；
右下角大面积留白，不放置任何主体、细节或元素。
```

**要点**
- **年代必须写死**，否则默认成现代或古装。开头就写「1997年，河北邯郸，国营棉纺厂家属院」这种三件套（年 + 地 + 具体场所）。
- **「现实主义」靠细节落实，不靠形容词**。把抽象要求换成可画的物件：不说「很穷」，说「洗干净得发白的工作服」「磕瘪的铝饭盒」「虎口一道发白的旧疤」「手指缝里洗不净的机油」。
- **调性靠情绪词定，模型读不到题材背景**。你要的是「幽默小说」它并不知道；必须写进 prompt：「明快、松弛、带市井喜感，是一幅俏皮的风俗速写，不阴郁、不悲剧」。漏了这句，年代题材默认往沉重、苦情、强对比走（实测封面因此被否）。
- **同组图里的人物给「标识包」，否则会塌成同一张脸**（2026-09-26 修正，原写「不写五官」是错的）。每个角色固定五个维度，跨图复用同一套措辞，同时拿到辨识度和跨图一致性：

  | 维度 | 48 岁钳工 | 43 岁下岗女工 |
  |---|---|---|
  | 脸型骨相 | 方脸、下颌宽有棱角 | 瘦削瓜子脸、高颧骨、下巴尖 |
  | 五官 | 浓眉压眼、鼻头大而圆、厚嘴唇 | 细眉薄唇 |
  | 发型 | 短板寸、鬓角花白 | 齐耳短发别在耳后、脸侧碎发 |
  | 体态 | 脖子粗短、肩膀又宽又厚 | 脖子细、肩膀窄 |
  | 标志物 | 磕瘪的铝饭盒、虎口旧疤 | 圆框金属老花镜、碎花布围裙 |

  末尾再钉一句「两人的脸型轮廓差异极大，绝不相同」，比只说「一个方一个瘦」有效得多。单张图、不涉及跨图辨识时，面部仍可只给方向（侧脸、低头、不笑）以降低崩脸概率。
- **封面要「有戏的场面」，不要实物空镜**（2026-09-26 修正）。原用「闩死的门」这类实物隐喻做封面，反馈太阴暗；改成「女人坐门槛抱门框举符、男人在后摊手无奈、胡同远景摩托」这种带表情和冲突的场面后通过。幽默调性尤其需要表情和动作。
- **光影用一个光源**（台灯 / 桥洞外日光 / 楼道灯），明暗对比拉出来，简笔才有体量感。要「少灰阶、线条为主」就把后缀写成「白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影」——只说「简笔」仍会给出大块排线阴影。
- 尺寸：插图 `1536x1024`（3:2）；封面 `1408x704`（2:1），裁水印后用 `add_frame.py --ratio 2.35` 裁成 2.35:1，再 `sips -z 383 900` 缩到微信头条尺寸。要留白边再加 `--frame`。
- 次要人物少写——**前景留一两个人，其余用手和袖口**，画面更干净，也更像文学插图。

**实测有效的一组分镜（1997 北方工厂家庭，《关口》5 张，v2 通过版）**
`守门`（长卷封面：女人坐门槛、抱门框、举黄纸符瞪眼嚷，男人在后摊手无奈，门外胡同与摩托）→ `书案台灯`（饭桌摊万年历，女人戴老花镜排八字，男人解着扣子进门）→ `锯末搓手`（男人水管下用锯末搓手、叼着长烟灰，门口探进儿子的头）→ `桥下问卦`（桥洞下戴墨镜的老头转石球，女人蹲在旁边抓布包）→ `一碗寿面`（热气腾腾的锅 + 卧两个鸡蛋的面碗推过去，镜片被哈白）。

> **v1 为什么被否**（2026-09-26）：「闩死的门」实物隐喻封面被评为「太阴暗」，且 4 张插图里人物脸型雷同（都塌成同一张中年圆脸）、画面满构图无留白、灰阶偏多。四条修正分别是：① 封面换成有表情有冲突的场面；② 人物上「标识包」；③ 相框感后期加；④ 后缀加「几乎不用灰阶」。
>
> 结论：**文学感的实物隐喻适合正文插图，不适合幽默调性的封面**。封面优先选有戏、有表情、能一眼读出矛盾的场面。
