# 风格库 · Style Library

给用过的生图风格起名字。命名之后，以后只说名字或 `style: <slug>`，不必重述整段 prompt 后缀。

- 新增风格往这里追加，按「名字 → 配方 → 可复用后缀 → 后期参数」写全。
- 改了配方，要同步 `SKILL.md` 对应章节。
- 名字一旦用过（写进过文章/存档/对话），**只加不改**；真要改就旧名留作别名。

## 白纸速写 · `paper-sketch`

**一句话**：白纸上一幅钢笔速写——白底黑线，几乎不上灰阶，四周一圈纯白当画框。

| 项 | 内容 |
|---|---|
| 首用 | 2026-09-26，《关口》公众号配图（1997 北方工厂家庭 / 幽默市井小说） |
| 定位 | 中文文学、纪实、年代题材。**调性不写死在风格里**——靠支柱 4 的情绪词切换：市井小说用「轻松、有戏」，纪实/评论用「沉静、克制、郑重」（两种都实测过，见文末「调性变体」） |
| 底色 | 纯白，不留纸纹、不做旧 |
| 用色 | 只有黑、白 + 极少量灰阶，无任何色彩 |
| 画框 | **可选件**。用户要求时后期加纯白留白边（prompt 求不来）；**默认不加** |

### 四根支柱（**线 / 笔 / 调**缺一就变味；**框**是可选项，默认不做）

1. **线** — 「白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影」。
   只写「简笔线条」不够，模型仍会给大块排线阴影。这一句是「线条感」的开关。
2. **笔** — 「笔触轻快流畅，像钢笔速写」。这一句决定出来是雅致速写还是硬朗版画。
3. **框（可选，默认不做）** — 四周纯白留白边。**prompt 求不来**（2026-09-26 实测：写了「四周留整圈空白」，模型基本不遵守），要加只能后期 `add_frame.py --frame --line 0`。**用户没明确要求留白边，就不加**——留白是审美偏好，不是这个风格的必备件。
4. **调** — 情绪词必须写死，且**要跟着题材换**：
   - 市井/幽默题材 →「明快、松弛、带市井喜感，是一幅俏皮的风俗速写，不阴郁、不悲剧」。
     漏了这句，年代题材默认往沉重、苦情、强对比走（封面曾因此被否）。
   - 纪实/评论/历史题材 →「沉静、克制、郑重，是纪实速写，带一点苍凉，不阴郁、不苦情、不夸张煽情」。
     **关键是后半截「不……不……不……」**：既要拉出厚重感，又要把默认的苦情/煽情压住。
   - 反面教训：**别把情绪词跟风格名绑死**。上一版这里只写了「轻松、有戏」，于是"白纸速写＝轻调"被当成风格属性；其实它只是一组可替换的情绪词。

横向两条硬要求：

- **写实比例 + 年代细节**。抽象要求换成可画的物件：不说「很穷」，说「洗得发白的工作服」「磕瘪的铝饭盒」「虎口一道发白的旧疤」。
- **人物给「标识包」**，五维（脸型骨相 / 五官 / 发型 / 体态 / 标志物），跨图复用同一套措辞；末尾再钉一句「两人的脸型轮廓差异极大，绝不相同」。
  只写「一个方脸一个瘦脸」会塌成同一张脸。详见 `SKILL.md` 表格。

### 统一 prompt 后缀（每张末尾都粘）

```
纯粹黑白线描，白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影；
笔触轻快流畅，像钢笔速写；写实比例与真实的九十年代细节，人物不做美化、
不卡通化，但神态生动有戏。人物和主要物件集中在画面中间，四周留出整圈空白，
人和物件都不许碰到画面边缘，构图像速写本上的一小幅画。画面不出现任何文字、
数字、书法、落款或印章；右下角留出大面积空白，不放置任何主体或细节。
```

> 后缀里仍保留「四周留整圈空白」「右下角留白」——实测不生效，但写上无害，能略微降低出血概率。**真正的留白靠后期**，不要指望 prompt。
> `size` 用标准比例：插图 `1536x1024`（3:2）；封面 `1408x704`（2:1），再裁到目标比例。

### 后期（必做：裁水印；留白边框可选）

```bash
S=scripts/add_frame.py

# 默认：只裁水印，不加框
python3 "$S" in.png out.png --crop-bottom 80
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35                    # 微信头条封面（无白边），再 sips -z 383 900

# 用户明确要求留白边时，才加 --frame
python3 "$S" in.png out.png --crop-bottom 80 --frame --line 0
python3 "$S" in.png out.png --crop-bottom 70 --ratio 2.35 --frame --line 0  # 留白后恰为 2.35:1
python3 "$S" in.png out.png --crop-bottom 70 --frame --ratio 1 --pad 0.04 --line 0  # 方形次条封面
```

先量水印再裁（见 `SKILL.md`「裁掉右下角水印」）。**加框是可选项**，用户没要求就不加。
一旦要加，`--line 0` 是标准做法：线条画本身已满是黑色轮廓，再加画框线显生硬。
白边取短边 `0.06`；边框色＝底色纯白，所以看不出一圈"框"，只觉得是留白。

### 调性变体 · 沉郁纪实（2026-10-06，《长城》配图实测）

同一套风格，把支柱 4 的情绪词整体替换即可，**其余配方（线/笔/框）一个字不动**。

**替换用的后缀**（在原后缀基础上改两处：年代细节项、情绪词项）：
```
纯粹黑白线描，白底黑线为主，几乎不用灰阶，只用极少量稀疏排线暗示阴影；
笔触轻快流畅，像钢笔速写；写实比例与真实的物件细节，人物不做美化、不卡通化，神态生动；
调子沉静、克制、郑重，是纪实速写，带一点苍凉，不阴郁、不苦情、不夸张煽情；
人物和主要物件集中在画面中间，四周留出整圈空白，人和物件都不许碰到画面边缘，
构图像速写本上的一小幅画；画面不出现任何文字、数字、书法、落款或印章；
右下角留出大面积空白，不放置任何主体或细节。
```

**实测有效的分镜（《长城》1 封面 + 5 插图）**
`两种下场`（长卷封面：左半博物馆展台上一尊**无头菩萨身躯**+一个极小的人仰看 ｜ 右半山脊上长城被挖开豁口、渣土车穿过）→ `石窟无头`（石壁佛龛内数尊佛像头部位置全空、只剩凿切断面，前景一尊残缺身躯）→ `墙上豁口`（夯土长城拦腰掏开，断面露层理，渣土车从豁口开过）→ `界桩迟到`（**远景**：夯土长城沿山脊蜿蜒入远山，中段壑口堆着碎石，墙顶一个小人影沿墙走远；近处荒草坡上立着一根矮墩墩的水泥界桩）→ `女儿问砖`（城墙顶上九岁女孩仰头按砖、父亲手搭垛口低头看她，长城沿山脊蜿蜒远去）→ `清早守墙`（天蒙蒙亮，老人背蛇皮袋、拄木杖走在长城残墙顶）。

三条可复用结论：

- **素白无字的「竖长物件」要慎用——十有八九被读成「无字碑」**。`界桩迟到` 第一版让界桩素白无字、竖立在画面正中（一个人蹲在旁边），反馈是"看着像一块无字碑"，情绪整个跑偏。改远景后成立：**把桩改成矮胖的方块墩子**（有底盘、斜切顶），素白无字才只是"没写字"，而不是"等着刻字"。
  **形状定调，空白只负责不抢戏。** 想表达"制度立了、执行没到"，靠"新桩 vs 老裂口"的并置，不靠把物件画大。
- **人小、物长 = 尺度对比，靠 prompt 里把比例写出来**。第一版 `女儿问砖` 只说"父女两人都很小，城墙很长"，出来是一段局部墙；改成"**父女两人非常小，长城很长很高，从他俩脚下一路延伸到画面深处和远处的山脊上**"才成立。抽象形容词不够，要给出"延伸到画面深处和远处"这种可画的走向。
- **实测尺寸（可直接核对）**：插图 `1536x1024` → 裁底 80 → **`1536x944`（默认，无框）**；加白边时 `1670x1078`（四周各加 67px = pad 56 + gap 11）。封面 `1408x704` → 裁底 70 → `--ratio 2.35` → **`1408x600`（默认，无框，比值 2.347）**；加白边时 `1496x638`，比值 2.3448（与 2.35 差 0.2%，视觉无感，可接受）。
- **水印实测位置**：`1536x1024` 在 y≈955 起；`1408x704` 在 y≈650 起。裁 80 / 68 后右下角均为纯白，6 张全部验真通过。

### 有效分镜参考

`守门`（长卷封面：女人坐门槛、抱门框、举黄纸符瞪眼嚷，男人在后摊手无奈，门外胡同与摩托）→ `书案台灯`（饭桌摊万年历，女人戴老花镜排八字，男人解着扣子进门）→ `锯末搓手`（男人水管下用锯末搓手、叼着长烟灰，门口探进儿子的头）→ `桥下问卦`（桥洞下戴墨镜的老头转石球，女人蹲在旁边抓布包）→ `一碗寿面`（热气腾腾的锅 + 卧两个鸡蛋的面碗推过去，镜片被哈白）。

**封面要「有戏的场面」，不要实物空镜**。v1 用「闩死的门」做实物隐喻，被评为太阴暗；换成有表情、有冲突的场面后通过。实物隐喻适合正文插图，不适合需要吸引点击的封面。

> **补充（2026-10-06）**：上面这条是**市井/幽默题材**的结论，别当通则。纪实、评论、历史题材的封面可以走
> **「左右两半对照的长卷」**——不用表情冲突，靠两组画面的并置把标题的矛盾直接摆出来
> （《长城》封面：左半展台上无头菩萨身躯 ｜ 右半山脊上被挖开的长城与渣土车）。
> 两条都成立，区别在于**题材要让读者"先看懂矛盾"还是"先被逗住"**。

## 水墨文艺风 · `ink-wash`

**一句话**：淡墨宣纸，留白多，左下角一枚朱砂印。

| 项 | 内容 |
|---|---|
| 首用 | 2026-09-15，历史文化类公众号 |
| 定位 | 历史、文化、人文题材；调性偏静、雅 |

**统一 prompt 后缀**：

```
淡墨为主，古旧宣纸质感，文艺气质，留白多；画面不出现任何文字、题跋或印章字样；
左下角一枚极简朱砂印记；右下角留白，不放置任何元素。
```

**要点**

- 前缀用 4 字场景词（如「葫芦小院」「墙里墙外」），既是防覆盖标记，也让模型先抓住画面主题。
- 调色只允许三种：淡墨 + 极淡赭石/赭黄（暖）+ 一点极淡花青或藤黄（冷/光）。**朱砂只用在左下角那枚印上**。
- 留白要写进正文，不能只写「留白多」。例：「湖面以大片留白化作雾气」「地面留白成刺眼的白光」。
- 人物用「寥寥数笔勾勒」「身形疏淡」，不写面部细节——写意比工笔稳。
- **年代不写死就默认古装**。要现代场景必须点明「现代装束」，否则出来是水墨古装。
- 封面走横向长卷 `1408x704`，裁 `900x383`；内容插图 `1536x1024`。
- 组图与文章走向对齐：**一张封面立主题，其余按小标题顺序各配一张**，不要六张同风格空镜。

**有效分镜**：`北国拆墙`（长卷：北国城郭 ｜ 江南水乡，中间一道墙断开豁口）→ `葫芦小院` → `午门排队` → `西湖无墙` → `墙里墙外`（一道素白高墙横贯，墙外一人仰头看，墙内一人背墙坐）→ `霜降葫芦`。
其中「墙里墙外」这类**用构图直接对应论点**的图，比纯风景插图被引用率高得多。

## 白描水墨 · `baimiao-ink`（别名：简笔入水墨）

**一句话**：一幅画里分两层笔法——**人物只用白描细线、线条内部全留白**，**环境与器物用水墨浓淡渲染出体积**；只有黑、灰、宣纸白三色。

| 项 | 内容 |
|---|---|
| 首用 | 2026-10-17，《爱尔兰大饥荒》公众号配图（1 封面 + 5 插图，**6/6 一次过**） |
| 定位 | 历史、纪实、灾难/苦难题材；调性肃穆、克制、反思。人物必须「在场」，不能通篇空镜 |
| 底色 | 古旧宣纸（会带极轻的暖褐调，见下「实测」） |
| 用色 | **只有黑、灰、宣纸白三色。没有朱砂印**——`ink-wash` 那枚印是它的件，本风格不用 |
| 画框 | 默认不加 |

### 两根支柱（**必须分别写两遍、各自钉到具体部件**）

只写「简笔和水墨相结合」会出成单一风格——**模型不会自己分工**，必须点名谁用哪种笔法。

1. **人物＝简笔画法**：
   「画面里所有人物只用几根干净流畅的细线勾出轮廓，线条内部**完全留白、不施渲染、不加阴影明暗**，属**中国传统白描／线描速写**，不是卡通、不是扁平插画、不是矢量图。」
   —— 三个负面词是必须的：漏了「不是卡通／不是扁平插画」，出来就是彩色扁平插画。
2. **环境＝水墨画法**：
   「土地、海面、天空、建筑、林木与器物用浓淡墨块层层渲染出体积与质感，墨色有干湿浓淡变化，**造型写实、比例真实、细节交代清楚，不是大写意泼墨**。」
   —— 后半截是 `ink-wash` 的 **`ink-wash` 后缀反转**：水墨文艺风默认「寥寥数笔、写意」，本风格要**写实**，否则环境太虚、托不住人物。

### 人脸怎么处理（本风格 0 塌脸的关键）

**面部一律不刻五官**，全部用「低头 / 侧影 / 背影」处理，附一句「面部留白或以极淡墨色虚化」。
白描线不描五官 → 天然规避崩脸，也就不需要 `paper-sketch` 那套五维「标识包」（那套是给需要**面部辨识度**的跨图人物用的）。
反面：如果题材需要读者认出「这是同一个人」，本风格不合适，改用 `paper-sketch`。

### 古代场景的人物造型（朝代锚点，⚠️ 必带）

**2026-10-25《众口铄金》实测踩坑**：只写「战国／东汉／北宋／明代」+「古代平民」，人物画出**清末民初乃至现代**的样子——短发（甚至平头、寸头）、立领长衫、西装领、纽扣、中山装。白描线稿去掉了色彩与纹样，模型只剩一个默认值顶上，而这个默认值是**民国**。

**人物越多越错**（5 人以上必错）。因为每个人物是分开生成的，模型不会自发统一，一张画里常出现三四个时代混搭。

| 朝代 | 头发（**必须写，写「古代发型」无效**） | 冠巾 | 衣 |
|---|---|---|---|
| 先秦／战国 | 束发挽髻，可偏髻，用发带 | 无冠或小冠 | 深衣，交领右衽、宽袖、腰系大带 |
| 东汉 | 束发，以帻包住 | **巾帻**；士人加进贤冠 | 交领右衽长袍，宽袖 |
| 唐 | 束发 | 幞头 | 圆领袍或交领，革带 |
| 宋 | 束发 | 幞头／东坡巾／幅巾 | 圆领袍、直裰；士人可道袍式宽袖 |
| 明 | 束发，加**网巾** | **四方平定巾（方巾）／儒巾** | 圆领袍、直身、曳撒，宽袖 |

**四条必写**（少一条就漏）：

1. **头发要写束法，不写「古装」**：「全画人物的头发**一律束起挽成髻**，束在头顶或脑后，用发带或巾包住」。
   负面照抄：「**绝不是短发、平头、寸头、西式分头，不出现披发遮额**」。
2. **衣服要钉形制，负面要点名排除现代默认值**：「**交领右衽、宽袖、腰间系带、下摆长及脚踝**」；
   负面：「**不出现立领、翻领、衬衫领、西装领、纽扣、拉链、口袋、对襟短褂（马褂）、中山装**」。
   —— 马褂／长衫／中山装是模型最容易顶上来的一档，**必须逐个点名**，只写「古代服装」压不住。
3. **人群要写「统一」，这是多人场景唯一有效的句式**：「画面里**所有人一律为同一朝代的装束，发型与冠巾互相一致，没有一个人例外**，不得出现任何一个人穿现代服装、留短发或戴着与现代相同的帽子」。
4. **背影／侧影尤其要管「后脑」**：后脑勺是全组最容易暴露的一处——**短发是一个光圆弧，束发是一个髻或一团包住的巾**。
   写：「人物虽为背影，**后脑可见挽起的发髻（或以巾包住的头形）**，不是剪短的平头」。

**人多时再加一条降噪**（人物 6 个以上、且在远景时）：把细节层整体降级，减少模型发挥空间——
「所有远处人物**只画到肩头与束发的轮廓**，不画面部、不画衣纹、不画手指，成片化进淡墨里」。

**验证法**：出图后先只看**头**——有髻／有巾＝过；一片圆弧短发＝重出，改 prompt 无用，必须把「束发挽髻」「网巾／巾帻」「不是短发平头」三句同时补上。

### 统一 prompt 后缀（每张末尾都粘）

```
全画只有黑、灰、宣纸白三色，不出现任何彩色。画面用两种笔法并行：
水墨画法——土地、海面、天空、建筑、林木与器物用浓淡墨块层层渲染出体积与质感，
墨色有干湿浓淡变化，造型写实、比例真实、细节交代清楚，不是大写意泼墨；
简笔画法——画面里所有人物只用几根干净流畅的细线勾出轮廓，线条内部完全留白、
不施渲染、不加阴影明暗，属中国传统白描线描速写，不是卡通、不是扁平插画、不是矢量图；
人物面部不刻画五官，一律以低头、侧影或背影处理，面部留白或以极淡墨色虚化。
整体氛围肃穆、克制、沉静、反思，留白多，不热闹。淡墨为主，古旧宣纸质感；
画面不出现任何文字、数字、书法、题跋或印章；右下角大面积留白，不放置任何主体、细节或元素。
```

**⚠️ 不要照抄 `ink-wash` 的后缀**——它含「左下角一枚极简朱砂印记」，套进来就破「三色」这条。

### 变体 · 线描主导（佛像 / 器物 / 静物类，2026-10-17《佛像衣服》6 张实测）

用户说「**简笔水墨画**」时走这个变体：**连环境也从水墨渲染降为线描**，只在转折处留极少量淡墨，整体白远多于黑。与父风格的区别只有一条——父风格是「人物线 + 环境墨」两层，本变体是「**全线 + 一点墨**」。

**① 佛像的面部：不做正面近景，只画侧脸轮廓。**
实测三版全崩：正面「下半张脸」特写会补全成一张**圆胖和尚脸**，嘴唇画出两撇胡子；正侧脸（含鼻梁眼窝）出来是**仕女侧影**，不像佛。**有效解 = 只画一条侧脸轮廓线**，从鼻梁中段到下颌、脖颈，额头上方和头顶由画边切掉，并显式给三个佛像特征：

> 「侧脸饱满圆润，面颊有肉，**下巴圆钝**，**下巴底下有一道明显的弧形软肉**，**耳垂细长下垂**，嘴唇厚而内收、双唇轻合，鼻梁平直不高挺」

—— **长耳垂 + 双下巴弧线**这两个特征一给，脸就立刻从「仕女」变回「佛像」，比写「庄严」「慈悲」有效得多。负面补「不是仕女画、不是铅笔素描」。

**② 「保持对佛像的尊重」要落成可执行的负面清单**，光写「尊重」没用：
`佛像面相端正慈悲，神情庄严，不夸张变形、不漫画化、不戏谑、不破损`，另加构图层：佛像不被踩踏、不倒卧、不残缺、不做商品化处理。

**③ 「画面里不要只有孤零零的佛像」→ 每张配一个对照物**，三种配法轮换用：
- **对比佛像**（并置两尊风格迥异的，中间留一道竖向缝）—— 最适合「同与不同」的论点；
- **极小的人**（观众背影 / 工匠 / 供养人）—— 兼做尺度参照；
- **一只手 + 一件工具**（笔、凿子）—— 近景专用，人的在场感靠手就够。

**④ 人物要小，靠「写到具体部位」而不是写比例数值**：
`身高只到佛像膝盖`、`只到脚背那么高`、`不及佛像的膝部`——比「占画面 1/20」有效。数量照旧要钉死：「画面里只有两尊佛像和一个观众，不多不少」。

**⑤ 视角轮换表**（一篇 6 张的实测配法，避免全是平视空镜）：
广角平视（封面，两尊并置 + 中人）→ 中景并置（同时期两派对比）→ **广角俯视**（造像工地，脚手架）→ **近景侧脸轮廓**（贴金，笔尖 + 金痕）→ 对称中景（一个名字两张脸）→ **俯视微距**（案上小瓷像，人淡到化在纸里）。
微距那张人必然比物件大，属于**刻意反向比例**——交付时要主动说明，别当成违例。

**⑥ 极淡赭金是唯一允许的彩色**：`除了那一点极淡的赭金之外没有任何颜色`。用来画贴金痕、鎏金铜的高光，一次只点一处。

**实测后期（每批都要重量，不沿用旧值）**：`1536x1024` 水印上沿 **y≈956**，裁 96 → 1536x928；`1408x704` 上沿 **y≈660**，裁 70 后 `--ratio 2.35` → 1408x600，再 `sips -z 383 900`。

### 变体 · 漫画夸张（幽默／讽刺题材，2026-10-17《诺奖门口查证件》6 张一次过）

用户说「**简笔水墨画 + 幽默、夸张、小冒犯的漫画**」时走这个变体。**线与笔一个字不改，只换两样：情绪词、夸张的落点。**

**① 夸张只落在「比例与姿态」，绝不落在五官。**
巨门 vs 小到只及柱础的人；书比上半身还大、压得人后仰脚离地；翘着腿把票举过头顶撕；影子比本人放大三倍。面部照旧**不刻五官**（侧影／低头／背影）。
—— 这样既是漫画，又天然规避崩脸；画真实人物时也不构成可辨识面孔。

**② 情绪词换成这一句**（替换父风格那段「肃穆、克制、沉静」）：
```
姿态与比例刻意漫画化夸张，带幽默的俏皮和温和的讽刺，神情生动有戏，
不阴郁、不苦情、不煽情，也不丑化人物。
```
末句「**也不丑化人物**」是防「小冒犯」跑成刻薄的闸，必须留。

**③ 「嘴刻薄不如道具刻薄」**——让道具说难听话，比画表情、写文字都稳，还能守住「画面不出现任何文字」：
- 墙上一个**空画框**（奖章没了）；
- 书脊上一道墨线**划掉一截、中间跳过去**（缺了一卷）；
- 手里一块**空白牌子正往身后藏**（不写字也能读出「偷摘胸牌」）；
- 脚边一只**落下的空墨水瓶**。

**④ 分镜实测（诺奖题材）**：`查证件`（封面：巨门占半幅 + 小头长脖守门人捧巨册 + 四个小到柱础的歪队）
→ `写历史的`（抱巨书，罗马小兵从书页爬出摔地上）
→ `当面撕票`（翘腿举票过头顶撕，纸片纷飞，空画框，旁边空椅）
→ `抱吉他的`（弹电吉他的人平静，墙上巨大淡墨影子化成抱竖琴的吟游诗人甩头，影子是全画最大形体）
→ `别叫我诗人`（推眼镜挥手推辞，书堆比人高、散页乱飞 ｜ 一小摞线装书整齐）
→ `合上册子`（门缝光带 + 夹册子大步走远的背影）。

> 也适用于其他「评论／杂文」题材：**观点的冲突用体量对比和道具并置摆出来，不用表情**。

### 敏感题材怎么配（苦难/灾难/死亡类，本次实测）

- **不可画**：尸体、伤亡、行刑、血腥、施暴动作、被指认的受害者形象。
- **换成可画的等价物**，叙事照样保住：
  - 「地主寒冬驱赶佃农、掀房顶」→ **不画推搡**，改画**粥棚**（制度性羞辱：施粥附条件、长队）——力落在制度上，不落在人身上。
  - 「饥民饿死」→ 画**环境与物**（烂在地里的作物 + 一只手），不画倒地的人。
  - 「棺材船」→ 船画**远景**（小、模糊、正在离开），人物一律**背影**。
- **数量要钉死**：「只画三个人，不多不少」「队伍只画五个人，不多不少」——不写就多画（实测同轮）。
- **年代 + 地点写死**：如「1846 年冬天爱尔兰乡间」「1845 年爱尔兰某块被翻开的马铃薯地」，否则默认成古装中国。

### 实测有效的分镜（《爱尔兰大饥荒》1 封面 + 5 插图）

`粮食离岸`（长卷封面：近景左侧一个背对观众的空手农民 + 脚边空藤篮 ｜ 中景栈桥上粮袋、木桶、牛正被赶上帆船，货堆得很满 ｜ 远景灰海与桅杆。**一空一满，一眼读出「粮食离岸、人留在岸上」**）
→ `巴掌地块`（近景贫瘠小地块里农民弯腰挖土豆，中景一道干砌石墙分地，墙外远处是肥田与牛羊）
→ `烂在地里`（贴地近景静物：土里腐烂发黑的马铃薯 + 一只沾泥的手拨开泥土，全画只出现这一只手）
→ `海边滩涂`（三个人弯腰在退潮滩地拣拾贝类、采海藻，海面空无一物、没有船也没有渔网）
→ `雪地粥棚`（帆布棚下几口冒热气的锅，棚口一只手递出一碗粥，队伍五个人低头排开）
→ `海岸目送`（远景一艘帆船驶向灰白地平线，近景高坡上四个提包袱的背影沉默目送）

三条可复用结论：

- **封面用「一空一满」的并置**立矛盾，比实物隐喻和表情冲突都更适合苦难题材——读者先看懂矛盾，情绪自己上来。
- **一只手/一个背影就够**。苦难题材里，「只有一只手」「只有几道背影」比画满人群更有力，也天然避开崩脸与暴力。
- **负面清单要写在句子里，不能靠风格名暗示**。「海面上空无一物，没有船、没有渔网」必须写出来，否则模型一定往远处加两条船。
