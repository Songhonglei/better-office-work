# 连环画 Skill 路线图

最初的版本以白描、定妆、逐页验收和翻读为主，v1.1 到 v1.3 增加严格验收、版本恢复、多画风及 ComfyUI 生成。v1.4 和 v1.5 的范围根据实际制作与调试补齐。 [变更记录](CHANGELOG.md)

## v1.4　可复核的单册制作

- 让角色、物件和空间规则落到适用页，进入每页的出图提示和视觉检查结果。按共用规则修改范围标出受影响页。
- 样张先行，分段提交。候选与已选稿共存，按任务 ID 恢复，按版本复审和选择。
- ComfyUI Q4/Q6 支持整页生成和局部修订，保存裁图、蒙版、模型工作流和实际时间。用图像像素验证局部修订范围。
- 验收标准是旧项目保持可读，新项目未通过的视觉检查能拦住选稿交付，本机模型能完成实际出图与局部修订。 [逐页跟进](references/continuity.md)

## v1.5　整册协作与生产度量

- 已落地审图工作台。显示整册缩略图、同一细节的跨页局部及前后稿，并支持逐版本批注、位置标记和切换审图稿。用《雨夜书坊》的独立副本验证。 [工作台](references/review-workbench.md)
- 已落地单页返工队列。批注可转任务，保存优先级，按原 ComfyUI 任务编号恢复，完成后归档候选稿。分镜变更时会标记待跑任务，整册修订影响范围的预览待实现。
- 准备需要跨作品验证的质量基线，以首轮入册率、按原因归类的返工次数、局部修订时间和峰值内存衡量。用至少两册同量级作品比较 Q4/Q6，覆盖动作、对话、弱光和小道具。
- 打包独立的验收记录，包含桌面及窄屏翻页、深链接和选稿哈希。保留用户看图作为视觉判断依据。
