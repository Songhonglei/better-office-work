## v1.0.0 (2026-11-27)

**首版：从一部 20 页连环画的九轮返工里抽出的完整流程**

- **流程**：分镜 JSON → 拼 prompt → 定妆照 → 逐页出图 → 裁水印 → 校验 → 建站 → 发布，五个脚本可整套复制到新项目。
- **阅读器模板**：默认连续图文，可切单页翻页；进度条跳页；`#p12` 深链接（多次定时校正 + 用户滚动即停）。
- **29 条出图经验**（`references/prompt-playbook.md`）：
  - 人物一致性靠定妆照 + i2i，颜色与冠帽必须写进锚点，并带否定项。
  - 配角必须有独立锚点，否则穿主角衣冠、长主角的脸。
  - 「不要看镜头」要给具体注视对象；「不要雪白」要改成「比纸底深一档」。
  - 「两人共捧一物」必出两件——物件只交给一方。
  - 文字类物件换承载物（书架 → 木柜 + 卷轴端面）。
  - 人物贴底是模型先验，靠后期规则而非提示词。
  - 单根笔画错了重生比修图便宜；只改服饰颜色则相反，必须本地改。
- **建站脚本参数化**：`stories/_series.json` 管书架标题 / 副标题 / 页脚 / 计划书目，换系列不用改 HTML。
- **校验**：`verify.py` 查页数、尺寸（封面 1536×1024 / 内页 1536×944）、单页体积 ≤450KB。

首版来自《聊斋志异·崂山道士》20 页实作，累计约 40 张出图、九轮返工。
