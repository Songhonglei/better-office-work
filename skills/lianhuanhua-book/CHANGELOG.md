# Changelog

## 1.5.2
- 工作台新增首屏导航、页目筛选和下一处待审。
- 返工任务选择范围。局部任务可在原稿上圈选并调用 ComfyUI 蒙版编辑，候选直达同一区域的新旧对照，刷新链接后保留。

## 1.5.1
- 正文左对齐，文案区从插图左右边缘各内缩两个汉字宽。
- 工作台批注可进入单页返工队列。待运行任务可调整优先级或撤回，已提交任务按原 ComfyUI 编号续跑，结果以候选稿归档。

## 1.5.0
- 新增本机整册审图工作台，逐页缩略图、跨页细节、新旧稿并排、版本批注及画面标点。
- 审图稿选择独立于阅读稿，批注和选择跨刷新保留。
- 正文默认按自然段折行，优先补写画面与情节细节。保留旧工程明确设置的分行排版。

## 1.4.1
- 正文与插图同轴居中，保留主动换行及图片原始比例，封面默认隐藏旁白。
- 署名和页脚均可省略；旧稿可仅调整旁白分行，沿用已验收的图片版本。

## 1.4.0
- 用共用细节、适用页和单页检查项跟踪画面。规则进入提示词和页级指纹，视觉结论绑定到图像版本。
- ComfyUI 支持先跑样张、按页段出图和保存候选。出图与局部修订共用任务 ID、续跑及耗时记录。
- 新增 Q4/Q6 局部修订，按原图蒙版裁切推理，核验区外像素，检查通过后选择候选。

## 1.3.1
- 新连环画默认采用 3:2 横向构图。严格画幅在出图后检查原图比例，旧项目仍可沿用补边。
- 内置 Qwen 参考图预设在严格模式下独立设置生成宽高。

## 1.3.0
- 多画风预设、自定义时代/人物条件、可配置画幅和裁切。
- 本地 ComfyUI API 工作流适配，干跑、单页串行批量、参考图上传、任务恢复；ImageGen 和其他模型通过统一导入。
- 更新操作文档、技能元数据。
- 本机验证后补齐只读探测的候选值和数值范围检查，明确生图画幅与交付画幅的设置方式。
- 白描空镜提示省略人物专用的服饰、线条和视线描述；人物服装深浅依角色设定。

## 1.2.0
- 页级状态、不可覆盖的版本归档、内容指纹、审核、选择和回退。
- 原图及提示词保留、生成来源记录。

## 1.1.0
- 严格分镜/图片验收、重复页码预检、失败保留原站、清洁构建、内容哈希。
- 自包含项目初始化、依赖配置、回归测试。

## 1.0.0
- 传统白描连环画、人物定妆、29 条出图经验、静态阅读器。
