# 故事结构

每篇一份 `stories/<slug>.json`，slug 仅小写字母、数字、下划线、连字符，须与文件名一致。参照 `stories/_template.json`。

## 顶层字段

| 字段 | 说明 |
|---|---|
| slug / title / book / author | ID、书名、原作或系列、真实署名（可选，空时省略） |
| source / era / era_anchor | 来源、时代及实际服装/道具约束；现代故事不需要古装约束 |
| style | styles/ 下的文件名，不含扩展名 |
| summary / colophon | 简介和来源说明；准确填写实际来源 |
| negative | 可选，作品特定的排除要求 |
| cast | 人物数组，name 唯一，anchor 为外貌与服饰；可选 reference 为 cast/ 中相对文件名 |
| pages | 按 no 从 0 连续编号，不得重复，0 是 cover，其余 page；完成作品 12–20 页含封面 |
| output | 可选输出参数，见下 |
| generation | 模型生成宽高，省略时继承 output。新建横版连环画用 1248×832 起步 |

## 页面

```json
{"no":1,"kind":"page","title":"开场","caption":"清晨，他走出院门。","scene":"晨光，主角站在院门左侧，望向远处……","who":["主角"]}
```

`who: []` 是纯景物页；旧版省略 who 时用名称匹配并警告可能漏配者。正文 `caption` 必须非空，使用自然段读来连贯的旁白，补足本页动作、环境或人物反应，由版面自然折行。封面默认只排图和标题，确需旁白时才设置 `show_caption: true`。`caption_lines` 保留旧项目已有的分行效果。`scene` 写明时间、光线、角色位置、行为、视线对象、道具数量、陈设、明暗落点及景别。

画风文件可把人物专用描述包在 `[[cast]]` 与 `[[/cast]]` 之间。显式声明 `who: []` 的页面会略过这段文字。

建议故事结构：封面、动机与环境、冲突、转折、结局；页数按故事分配，不强制所有故事包含三处伏笔。

## 画幅和压缩

```json
"generation": {"width":1248,"height":832},
"output": {"width":1536,"height":1024,"fit":"strict","crop_bottom":0,"cover_crop_bottom":0,"quality":82,"max_kb":450}
```

横版连环画默认用 3:2。采用 `fit: "strict"` 时，生成配置和原图都须与未裁底的交付画布同宽高比，后处理等比例缩放。旧项目可以省略 `fit` 或设置 `"pad"` 来沿用白边补齐。封面和正文的裁底分别设置，默认均为 0。老白描故事若省略整个 `output`，正文仍保留原有的 80px 裁底。质量从指定值递减直到满足体积上限，超限时会报错。

若为角色指定 reference，实际文件放在 `assets/images/<slug>/cast/`。当前故事 prompt、参考文件内容、画幅规格共同形成版本指纹。修改任何一项都需要重新审查受影响页。

生成尺寸通常须为 8 的倍数。使用严格画幅的内置 Qwen 预设时，生成宽、高须为 32 的倍数。图像通过比例检查后仍需目视检查两侧是否有大块无意留白。版本记录包含当前画幅规格和参考图快照，供返工与回退时核对。
