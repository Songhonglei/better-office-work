# 整册审图工作台

在成书项目目录运行以下命令。工作台只在本机监听，有需要时可以指定其他端口。

```bash
python pipeline/review_workbench.py --slug my-book --port 8789
```

打开 `http://127.0.0.1:8789/`。左侧页目显示该册缩略图和未处理批注。上方选择显示的版本，打开「并排对照」可指定另一幅图。点击「设为审图稿」保存该页的工作台选稿，继续审查时会保留这一选择。正式成书沿用 `progress.py approve --version <id> --select` 和构建命令。

批注跟图片版本绑定。可选本页的细节标签，先在图上标点，再写批注。处理后可以标为已处理，也可以重新打开。批注和审图选择保存在 `assets/images/<slug>/workbench.json`，随项目归档即可，阅读站构建时不公开这一文件。

跨页对照读取 `continuity` 的页码。共用细节可设置面向读者的 `label`，例如 `"umbrella": {"label":"弯竹柄油纸伞","rule":"一把弯竹柄油纸伞。","pages":[0,2,3,10]}`。可用该页的 `review_focus` 为某个细节圈出局部，例如 `"review_focus": {"umbrella":[0.40,0.35,0.56,0.71]}`。四个坐标是相对于选用画幅的左、上、右、下，介于 0 与 1；没圈局部的页会展示整幅。切换审图稿后复核局部位置，构图变化大的历史稿可以点回整幅检查。

只比对一个历史稿时，保留工作台选稿即可。要试排新增文案或测试切换，又需要保留现有成品，先把分镜、版本档案和选稿记录复制到独立项目，在副本上建站并启动工作台。

## 返工队列

在一条批注下点「转为返工任务」，任务会保留该页、批注所在图片版本、原始说明和当时的分镜指纹。同一条批注重复点击会返回现有任务。默认用本机 Q4 重画这一整页，批注会写入该页提示词，图上的标点仍用于审图。

- 批注尽量说明「可见问题、期望画面、需要延续的细节」。例如「格窗位置与上一稿不一致；保留原机位，只缩小贴着瓦尖的水珠」。
- 只改伞柄、手腕、水珠等小范围时，用 [局部修订](comfyui.md) 画蒙版。整页重画可调整机位和场景关系，提示词中的保留要求仍需要并排验收。实机试跑中，水珠保留了，窗格却从左移到了右侧，因此保留阅读稿，将新图留在候选待审。
- 验证单页队列时，核对「批注页码与实际生成页一致」「超时后继续使用同一个提示编号」「只有指定页多了一条候选版本」「阅读稿的选中图片不变」。视觉判断单独写入批注或审核记录。

待运行任务可把优先级调为 1 到 5，5 最先执行，同级按进入顺序。可以撤回未开始的任务。点「运行下一项」执行一页，服务器接受任务后仍可关闭页面。若控制端超时或退出，任务在本机工作台会显示「可续跑」。点「续跑下一项」按原提示编号读取 ComfyUI，优先接回已提交的任务。分镜或适用细节规则已变更的待跑任务会标记过时，重新核对后再建任务。

生成完成后点「查看候选稿」和阅读稿并排复核，原选稿继续供阅读。任务记录写入 `assets/images/<slug>/rework.json`。命令行也可在该项目目录操作：

```bash
python pipeline/rework.py --slug my-book status
python pipeline/rework.py --slug my-book run
```
