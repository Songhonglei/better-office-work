# 小人书流水线

一本 20 页的图文书，最贵的不是画，是**返工**。这套流程把返工点提前到生成之前：
先把人物锚点写死、先把同框角色分开、先把动作写成可检验的句子，再出图。

## 何时用

- 用户要把一段故事做成「一页一景、上图下文」的连环画 / 小人书
- 需要 12 页以上、风格统一的系列插图，且要在网页上翻读
- 已有分镜文案，需要配图并发布成可分享的链接

不适用：单张插图、漫画分格、彩色绘本、需要连续动画的项目。

## 先定三件事（缺一不可）

1. **篇幅**：12—20 页。少于 12 页讲不完因果，多于 20 页成本陡增。第 0 页是封面。
2. **画风**：默认 `lianhuanhua-baimiao`（单色黑墨线描、宣纸白底、铁线描、淡墨皴染）。要换风格就改 `styles/<style>.txt`，别在 prompt 里临时加形容词。
3. **人物表**：主角 + **所有会被画出来的配角**。这是最容易漏、也最贵的一步，见下方硬规则 1。

## 快速开始

```bash
# 0. 建项目骨架（把技能资产复制到工作目录）
cp -r <skill>/pipeline <skill>/templates <skill>/styles <skill>/stories .
mkdir -p assets/images

# 1. 写分镜：stories/<slug>.json（照 stories/_template.json 抄）
#    同时写 stories/_series.json（书架标题、页脚、计划书目；照 _series.example.json 抄）

# 2. 拼 prompt
python3 pipeline/make_prompts.py --slug <slug>

# 3. 出定妆照 → 逐页出图 → 落到 assets/images/<slug>/_raw/NN-页名.png（序号两位）

# 4. 后期 + 校验
python3 pipeline/post_process.py --slug <slug>
python3 pipeline/verify.py --slug <slug>

# 5. 建站 + 本地预览
python3 pipeline/build_site.py
./serve.sh 8788

# 6. 发布：site/ 是纯静态站，交给任意静态托管即可
#    （WorkBuddy 的「发布为应用」/ Vercel / Netlify / GitHub Pages 都行）
```

### 出图这一步怎么落

1. `pipeline/make_prompts.py` 生成的 `assets/images/<slug>/prompts/NN-页名.txt` 就是这一页的整段 prompt，**原样**喂给图像生成工具（ImageGen 或任何支持参考图的模型），不要临时改写。
2. 参考图只挂人物定妆照：主角 `image1`，第二位角色 `image2`。**不要挂场景图**——挂场景图会把上一页的构图一起抄过来。
3. 生成尺寸 1536×1024。封面存 `00-封面.png`，后期不裁底（右下角水印局部清除）；其余页存 `NN-页名.png`，后期裁掉底部 80px 去水印。
4. 出图落盘后先目视三查（水印、脚/衣摆、同框角色是否撞脸撞衫），再跑 `pipeline/post_process.py`。

## 硬规则（违反必返工）

1. **配角也要进 `cast`。** `scene` 里点名的每个角色都必须在 `cast` 有同名锚点，否则他会穿主角的衣冠、长主角的脸。拼 prompt 时「所有人脸型差异极大」只在锚点 ≥2 时出现。
2. **锚点写死颜色与冠帽**，并带否定项（「深黑方巾，不是浅灰色包头布」）。
3. **每个主要角色先出定妆照**，逐页挂 `image1`；双人场景 `image1` + `image2`。i2i 锁相貌不锁构图。
4. **同框不超过三人**，能两个讲清就别放第三个；必须有第三人时让他背身或只露半身。
5. **视线必须有对象**（看着碗 / 看着对方 / 看着自己的掌心）。没有对象，模型默认看向镜头。
6. **物件数量写死，且只交给一方**：写「画面里只有一只碗，这只碗只在师兄手里」，不要写「两人共捧」。
7. **「细节丰富」落在陈设与投影，不要整张加灰**；人物保持素白，重色压在墙根、器物投影、地面。
8. **环境明暗用相对量**：「灰度比宣纸底色深一档」，不写「不要太白」。
9. **文字类物件换承载物**：不画一排书，画木柜加卷轴端面。
10. **人物贴底是模型先验**，别为脚出画反复烧图；改后期规则或接受衣摆截断。
11. **单根笔画错了就重生**，不要修图（擦除留鬼影、补线对不上）。
12. **每页交付三查**：尺寸体积、右下角水印、同框角色是否撞脸撞衫。

## 成本预期

- 单页 1—3 次出图；20 页通常 30—50 张（按所用模型的计费单位折算）
- 返工集中在前 5 页定调阶段；风格与人物一旦锁住，后面很省
- 建议：**先做 1 页样张给用户确认**，再批量

## 交付清单

| 项 | 检查点 |
|---|---|
| 成书 | 页数、`pipeline/verify.py` 通过、封面与内页画幅符合约定 |
| 内容 | 三处伏笔各有回收；每页 caption 一到两句、结尾有钩子 |
| 站点 | 首页书架、阅读页连续图文、深链接 `#p12` 可直达 |
| 发布 | `site/` 已重建（改图后必须重建）、线上链接可打开 |
| 文档 | 每页画面与版本来源有一份配图说明、风格经验已回写 |

## 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 改了图但页面没变 | 浏览器缓存 / 未重建 site | 跑 `pipeline/build_site.py`；看 URL 指纹是否变 |
| 人物又长胡子 | 没用定妆照 | 挂 `image1`，并在锚点补「没有任何胡须」 |
| 配角穿主角衣服 | `cast` 缺该角色 | 补锚点 + 裁一张衣着参考图 |
| 一张图里出现两只碗 | 两人共捧 | 物件只交给一方 |
| 墙太白 / 背景发脏 | 用了绝对否定或整体加灰 | 改「比纸底深一档」；细节给陈设 |
| 页面刷新 404 | 服务没起 | `./serve.sh 8788` |
