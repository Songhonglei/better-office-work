# 内容数据约定

选择可维护的 JSON、YAML 或同等结构；格式不是强制的，以下字段语义应保持。页面直接从结构化内容生成，避免独立维护同一数字的多份副本。

## 建议数据实体

### report

- `title`：标题；`start_date`、`end_date`：报道区间；`user_timezone`：用户时区。
- `date_policy`：本期采用的公告/服务/其他日期口径。
- `checked_at`：事实核查截至时间；`rendered_at`：页面生成时间，不能伪装为重新核查时间。
- `count_unit`：事件、模型或变体；`inclusion_policy`：正式发布、预览和其他事件的收录方式。
- `summary`、`trends`：摘要与分析；每段支持引用来源ID或本期事件ID。

### sources

- `id`、`title`、`url`、`publisher`、`source_type`、`accessed_at`。
- `displayed_date`、`date_role`、`timezone`：页面实际显示的日期及含义。
- `read_status`：正文已读、浏览器已读、无法读取等；`supports`：具体支持哪些事实。
- `evidence_note`：短摘要、必要限定与冲突说明；可选本地快照引用。

来源编号在渲染时按稳定顺序生成；正文存ID，不手工写死数字。删改事件后，仍被图注、核查说明或其他事件使用的来源不能误删。

### events

- `id`、`name`、`publisher`、`region`；地区未知时留空或说明，不能从域名和模型名猜测。
- `event_kind`：新模型、版本更新、预览、权重开放、渠道接入等。
- `display_date`、`date_role`、`date_sources`、`related_dates`、`date_confidence`。
- `availability`、`availability_sources`；`weights_status`、`weights_sources`、`license`。
- `variants`：同次公告涉及的具名模型/变体，包含各自规格差异。
- `specs`：总参数、激活参数、组件参数、输入/输出模态、训练长度、服务窗口、最大输出、定价及各自证据。
- `summary`、`use_cases`、`limitations`、`source_ids`。
- `include_main`、`count_as_release`、`editorial_group`：控制展示与计数；分组是编辑判断。

同一模型的正式首发与后续开放权重是两个不同事件，可通过同一模型ID关联。后者可以入选“开放动态”，但不能再次计入“新模型首发”。

### retained_candidates

- 候选名称、已知事实、未确定问题、读取过的来源、未进入主清单的原因。
- 原因区分：日期不足、区间外、仅预告、渠道接入、非模型产品更新等。

### assets

- `id`、本地文件、媒体类型、用途、替代文本、图注。
- `origin`：官方网络素材、自制数据图或AI概念图。
- 官方素材：发布页、原图地址、发布方、版权/许可说明的已知边界。
- AI图：生成方式、完整提示词、概念属性说明；不能挂在厂商图片出处下。
- 自制图：原始数据引用、分组或计算规则，明确有无编辑判断。
- 记录资源散列可帮助确认“只换首图”时其他官方图片未被改动。

## 计数规则

先定义计数单位，再计算：

- 日期轴和发布分布按主清单事件统计。
- 模型/变体数按实际具名对象计算，并说明同批发布如何合并。
- 正式公告、受限访问、预览可能跨维度；如果页面分成互斥的展示组，应明确规则，不能重复相加。
- 已开放权重的事件集合独立计算，不与正式公告集合混为一谈。
- 多次转载、镜像、同名别称和同事件的平台转发不能增加事件数量。
- 概览、筛选按钮、图表、摘要数字和来源索引从同一数据得到。

## 增量修改的依赖关系

| 用户修改 | 需要更新 | 通常应保留 |
| --- | --- | --- |
| 起止日期 | 区间、增量检索、归属、统计、摘要、趋势、文件名 | 未受影响事件的已读证据和接受的视觉 |
| 某项事实 | 对应数据、证据、派生结论 | 无关事件和图片 |
| 替换首图 | 首图文件、嵌入数据、替代文本、图注、放大说明、来源记录 | 其他官方配图和正文 |
| 默认折叠 | 指定章节结构、初始状态、引用展开及打印逻辑 | 新闻事实、统计、其他章节 |
| 回退图片 | 上一被接受版本的图片及相关说明 | 未被要求回退的改动 |

修改后只运行与这些依赖有关的检查。不能仅更新表面标题，也不因单张图更换重做全期研究。
