# ai-model-weekly

核实全球 AI / LLM 模型发布，生成图文中文 HTML 单文件周报，也可增量修改已有周报。

版本：1.0.0 · 许可证：[MIT](LICENSE)

## 能做什么

- 按指定起止日研究模型发布，主动覆盖中国、美国及其他地区。
- 分开记录公告、服务上线、权重开放与平台上架日期，区分正式版、预览、访问条件和权重状态。
- 生成摘要、发布清单、参数、趋势、配图与可回溯来源；图片与样式内嵌，离线可读。
- 支持改区间、换首图、合并折叠章节与回退；核查说明和来源索引默认折叠。

这是 **Agent指令型技能**，由宿主Agent完成研究、文件生成和检查；不附带固定渲染器、一键CLI或自动新闻抓取服务。不会自动发布网站、发送消息或创建定时任务。

## 使用前提

宿主Agent需要网页检索、官方正文读取和本地文件读写能力。浏览器用于动态页面与视觉QA；缺少浏览器时需披露未完成的检查。没有特定浏览器插件、模型API密钥或Python依赖的硬性要求。仅在选用AI封面方案时才需要图像生成工具。

无法联网核实的内容只能作为待核实草稿，不能包装成已核实正式发布。第三方网站是否可访问不由本技能保证。

## 安装

克隆此仓库后，复制完整的 `skills/ai-model-weekly/` 目录，保留其中的 `references/` 和 `agents/`。

Codex示例（在仓库根目录执行）：

```bash
mkdir -p ~/.agents/skills
cp -R skills/ai-model-weekly ~/.agents/skills/
```

其他Agent使用其实际支持的Skill目录。已有同名安装时，先比较并保留本地改动，再决定更新；不直接覆盖唯一副本。宿主未发现新Skill时，刷新Skill列表或重新打开会话。

## 调用示例

新建一期：

> 使用 $ai-model-weekly 研究2026年11月1日至7日的全球AI模型发布，优先正式发布，核实官方日期和来源，生成中文HTML单文件周报，配图优先使用官方素材。

修改报道区间：

> 使用 $ai-model-weekly 把这份已有HTML周报的区间改为新的起止日，补查新增日期，重算清单、日期轴和统计，保留现有排版。

替换首图：

> 使用 $ai-model-weekly 只替换这份HTML的首图及对应图注、来源和放大说明，其他官方配图与核查内容保持不变。

修改已有文件时，同时给出文件路径或当前任务中可访问的文件。默认周规则为用户时区的周一至周日；明确起止日优先。

## 输出与边界

最终交付一个可直接打开的HTML文件。内容数据、下载和检查记录放任务工作区，放在Skill安装目录之外；不把周报、缓存和证据快照写进安装包。

模型能力、参数、价格和评测来自所读证据；本技能不自动实测模型，也不保证穷尽全球所有发布。网络素材须注明来源；概念封面须标为AI生成，不冒充厂商截图或发布现场。
