# macOS 合盖与电源操作

See [CHANGELOG.md](./CHANGELOG.md).

把自然语言需求转为最小范围、可恢复的电源方案。默认中文，先说结果；进度标题用图标加 2–7 个中文字符。

## 运行前提与交接

- 命令必须在用户要设置的目标 Mac 上执行。先根据工具的主机/连接信息确认执行目标，并用 `uname -s` 核实为 `Darwin`；仅检测到 macOS 不足以证明是目标机器。远端 Linux、容器或另一台 Mac 的结果不能代表用户电脑。
- 只读查询需要目标 Mac 的 Shell；使用 macOS 自带的 `sw_vers`、`sysctl`、`pmset`、`system_profiler`，临时防休眠使用 `/usr/bin/caffeinate`，无需安装第三方包。持久写入通常需要目标 Mac 的管理员认证；界面操作需要可用的系统设置控制工具。
- 没有目标 Mac Shell 时，将只读命令交给用户在该 Mac 的“终端”执行，先运行 `uname -s`、`pmset -g custom`、`pmset -g batt` 并返回结果，再生成具体方案。合盖需求再补充机型和显示器查询。命令不可用时报告缺失项，不把未知状态当作已符合。
- 只能手动设置时，也先展示方案并取得确认，再给出具体命令或匹配实际界面的操作步骤，以及回查命令。用户回传结果前标记“待执行/待验证”，不宣称已经设置完成。

## 先查询，再确认执行

1. 提取目标：合盖是否继续运行、系统是否允许空闲休眠、屏幕是否允许熄灭、适用电源（电池/接电/两者）、有效期（临时/指定时长/长期）。不要把“不休眠”自动解释为屏幕永亮或关闭冬眠。临时需求优先临时方案；未明确的范围若影响结果，集中澄清。
2. 只读检查实际机器，不把历史对话里的状态当成当前事实：

   ```bash
   sw_vers
   sysctl -n hw.model
   pmset -g custom
   pmset -g batt
   pmset -g assertions
   ```

   合盖需求再查 `system_profiler SPDisplaysDataType`，按需核实外接键鼠。只输出相关信息；按需读本机 `man pmset`、`man caffeinate`，系统设置标签以实际版本为准。
3. 展示待执行方案：当前值→目标值、适用电源、有效期、是否覆盖合盖、恢复方式。保留此次涉及的原值；持久设置可在工作目录保存带时间戳的快照，不包含无关个人信息。
4. **真正执行前必须请求用户确认并等待答复。** 这是用户对本技能的明确要求。“帮我设置”“合盖不休眠”只授权准备方案。一份具体方案的一次确认覆盖列出的批量操作；同范围常规重试不重复确认。扩大范围、更换方案、安装或开机自启需重新确认。查询无需确认。

   确认示例：“将接电时系统空闲休眠由 10 分钟改为永不；屏幕仍可熄灭，电池设置保持当前值。这个设置不保证覆盖合盖睡眠，可恢复为 10 分钟。确认执行吗？”

   确认前不得运行 `pmset` 写入、启动/停止 `caffeinate`、切换设置开关、安装软件或创建自动启动任务。未答复时停在方案，沉默不是同意。

## 选择最小可用方案

### 临时防休眠

- `caffeinate -i` 防止系统空闲睡眠，通常允许屏幕熄灭。仅用户要求屏幕常亮才加 `-d`；`-m` 仅用于明确的磁盘需求。
- `-s` 防系统睡眠断言仅在接电时有效，不能宣称电池模式也生效。`-u` 是用户活动断言，未指定超时时默认仅 5 秒，不能当作永久防休眠依据。
- 在展示确认方案前匹配电源范围：
  - 电池和接电都防止空闲睡眠：使用 `-i`；`-i` 不区分供电来源。
  - 仅接电时防止系统睡眠：使用单独的 `-s`（可加时长或任务参数）。不要同时加 `-i`，否则电池时仍会防止空闲睡眠；`-d`、`-m` 也没有接电限定，不能未经说明附加。拔电后 `-s` 的断言不再提供防睡眠效果，进程可以继续存在。
  - 仅电池时防休眠，或仅接电时屏幕常亮：`caffeinate` 没有直接匹配的电源过滤参数。使用已核实支持该范围的工具；没有可用工具时，明确告知限制并提出具体替代方案（例如两种电源都有效，或相应电源的持久设置），等用户确认后执行。不能仅因当前使用某种电源就声称会话限定于该电源，也不临时增加后台轮询或自启方案。
- 指定时长用 `-t 秒数`；等待任务可用 `-w PID` 或包装命令。
- 确认后可后台启动。例如“两种电源均防空闲睡眠 2 小时”用 `nohup /usr/bin/caffeinate -i -t 7200 >/dev/null 2>&1 &`；“仅接电防系统睡眠 2 小时”用 `nohup /usr/bin/caffeinate -s -t 7200 >/dev/null 2>&1 &`。记录 `$!` 并核对进程与断言。参数来自此次确认方案，示例不是默认设置。
- 进程结束或重启后失效；无限期会话不等于重启后永久生效。不自动创建 LaunchAgent。
- 停止前重新核对记录的 PID 与命令，只停止对应会话，不用 `killall caffeinate` 影响其他任务。停止/恢复也先确认。

### 持久电源设置

- 优先系统支持的界面或 `pmset`，写入通常需要管理员权限。`-c` 接电、`-b` 电池、`-a` 所有电源；只改确认的范围与键。
- `sleep 0` 关闭系统空闲睡眠，`displaysleep 0` 关闭显示器空闲睡眠；分别控制，不能混淆。确认“只接电时不空闲睡眠”后可执行 `sudo pmset -c sleep 0`。
- 不为普通“不休眠”顺带修改 `hibernatemode`、`standby`、`autopoweroff`、`tcpkeepalive` 或删除 sleepimage；它们不是合盖开关。
- 不默认使用未核实当前系统支持与适用性的 `disablesleep` 等隐藏参数。高级方案需核实可靠资料和设备适用性，说明系统/手动睡眠行为的额外影响及恢复办法，再确认；无可靠依据则报告限制。
- 恢复使用此次保留的原值，不用 `pmset restoredefaults` 覆盖其他设置。

### 合盖继续运行

- **屏幕熄灭、系统空闲睡眠、合盖睡眠是不同事件。** `sleep 0`、系统“显示器关闭时防止自动睡眠”和 `caffeinate` 断言不足以证明合盖后仍运行。
- 优先核实该机型的合盖外接显示器模式：电源、外接显示器和输入设备是否满足要求。参照 [Apple 外接显示器合盖说明](https://support.apple.com/117373) 和 [外设批准说明](https://support.apple.com/102282)，具体以当前机型资料为准；不要把 M3 双屏条件推广到所有 Mac。
- “无外接屏合盖跑任务”或“电池供电合盖”先检查已有工具是否支持，并用维护者官方资料核实当前版本；普通防休眠不能替代该目标。安装工具或组件须纳入待确认方案。
- 无可验证方案时说明缺少条件与能达到的部分目标，不承诺全覆盖。不改安全权限、伪造传感器或绕过平台访问限制。
- 合盖持续运行方案确认时简短说明耗电/发热并提醒保持通风，不在包里持续运行。

## 管理员密码交接

- 用户在可交互本机终端或系统认证框输入密码；不要求发到聊天，不读取、记录或代输。
- 后台 PTY 出现 `Password:` 不代表用户看得见或能输入。先确保有真实可输入界面；不可交互时取消等待，给用户准确的一条命令在终端执行，随后回查。不要反复启动无效密码提示。
- 若平台工具禁止操作终端或某应用，尊重限制并交接给用户，不改用另一自动化手段绕过。
- 未完成管理员认证不能声称持久设置成功，也不能擅自换临时方案绕过原确认。

## 验证与交付

- 持久设置用 `pmset -g custom` 回查正确电源分组的目标键；临时设置核对进程命令与 `pmset -g assertions`。断言证明当前防休眠，不能证明合盖效果。
- 临时设置同时用 `pmset -g batt` 核对当前电源和已确认范围；仅接电的 `-s` 会话在电池供电时不能报告“当前防休眠生效”，应报告“会话已启动，接电时生效”。用户未做供电切换测试时，不把参数核对称为已实测切换效果。
- 合盖效果需用户实际合盖测试，或有授权且不中断任务的外部观测；按需查看 `pmset -g log` 中测试时间窗口的睡眠/唤醒事件。未测就写“合盖效果待验证”。
- 已是目标值直接报告“已符合”，无需写入。部分失败逐项报告，只对确认方案有限重试，不扩大修改。
- 最终简洁报告生效项、接电/电池范围、有效期、合盖验证状态和恢复命令。
- 立即睡眠、关机、重启会中断会话：先展示具体动作和影响、取得确认后执行，如实说明不能在会话中继续验证。
