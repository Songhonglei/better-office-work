# CHANGELOG

## [1.1.0] - 2026-03-20

### 新增
- 同一天支持创建多个日记文件，按序号自动命名（2026-03-20.md → 2026-03-20-2.md → ...）
- 无打开文件时点保存，弹出确认框引导用户保存为今日日记
- ✨ AI 排版按钮（Ctrl+Shift+F），调用 glm-5 接口对大段文字自动分段排版

### 修复
- 保存按钮在无文件状态下静默失败，现改为有明确提示和引导

## [1.0.0] - 2026-03-19

### 新增
- 初始发布：Markdown 日记编辑器，File System Access API
- 实时 Markdown 预览
- 图片粘贴/拖拽存储
- 30秒自动保存 + 失焦保存
- 云端同步（飞书 WebDAV）
- 键盘快捷键 Ctrl+N / Ctrl+S
